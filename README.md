# LoopStep — One Shoe. Every Terrain. Less Waste.

An Android application built with **Kotlin** and **Jetpack Compose**, rewritten from the original React prototype.

LoopStep is a modular footwear innovation built around a reinforced mechanical twist-lock sole system. Keep the shoe upper you love, swap the sole you need in under 10 seconds, and cut shoe landfill waste by up to 70%.

## Key Features

1. **Patented 45° Twist-Lock Mechanism**:
   - Interactive rotation dial with tactile detent feedback.
   - PA66-GF30 polymer ring engineered to withstand ~7,000 N loads and 10,000+ lock/unlock cycles.

2. **Modular Sole Editions & Complete Shoes**:
   - Standard Edition (8mm wave flex, city walking, ₹200).
   - Sports Edition (12mm kinetic TPU rebound insert, running/training, ₹500).
   - Trail Edition (15mm 5mm lugs with ballistic rock plate, hiking, ₹700).
   - Native Complete Shoes: LoopStep Terra, Drift, and Ridge.

3. **Custom Sole Studio**:
   - Calibrate sole stack thickness (8mm–18mm), durometer hardness (45A–75A), and tread patterns with live 2D topology rendering.
   - Dynamic weight and pricing calculation.

4. **3D Biometric Foot & Shoe Scanner**:
   - Laser caliper overlay calculating foot length, forefoot width, arch profile, and optimal EU sizing.

5. **Universal ReFit™ Adapter Kit**:
   - Turn existing sneakers (Nike, Adidas, Puma, Converse, Vans, etc.) into LoopStep-compatible shoes for ₹50.
   - 4-step illustrated DIY conversion guide and verified brand compatibility checker.

6. **Circularity & Social Impact**:
   - Real-time Circular Impact Calculator (CO₂ emissions avoided, landfill waste diverted, water conserved, and money saved).
   - 1:1 Social Impact donation program (1 spare sole donated to local cobbler micro-enterprises for every pair sold).
   - 10% Sole Return Program discount for circular recycling.
